# kub — Финансовый радар для бизнеса 🌊🧊

> **kub** — офлайн-приложение для предпринимателей и руководителей малого бизнеса. Помогает контролировать реальные деньги, избегать кассовых разрывов и автоматически резервировать налоги под ЕНС.

---

## 🧊 3 грани «kub»

1. **Безопасный остаток (Safe-to-Spend):**
   - Автоматически отделяет свободные деньги компании от авансов заказчиков, под которые ещё не подписаны закрывающие акты (КС-2/УПД).
   - Защищает от ложного ощущения богатства при получении предоплат.

2. **Налоговая копилка (Tax Reserve):**
   - Расчёт налогового резерва под ЕНС: **УСН Доходы 6%**, **УСН Доходы-Расходы 15%**, **Патент**.
   - Радар приближения к порогу **60 млн ₽** (контроль риска перехода на НДС с 2025 года).
   - Напоминания о ключевых датах ЕНП (25 число — подача уведомлений, 28 число — списание).

3. **Кассовый радар (Cash Gap Radar):**
   - Прогноз движения денежных средств (ДДС) на 30 и 90 дней вперёд.
   - Заблаговременное выявление дефицита и практические рекомендации (перенос необязательных платежей, факторинг, авансирование).

## 🔒 Безопасность и офлайн-принцип

- **100% Offline-First**: Все финансовые данные хранятся исключительно на устройстве. Никаких внешних облачных баз или сторонних серверов.
- **Шифрование SQLCipher (AES-256)**: Локальная база данных Room зашифрована на уровне страниц.
- **Аппаратный ключ (Android Keystore)**: Парольная фраза для базы защищена криптографическим ключом, хранящимся в TEE / StrongBox чипе смартфона.

---

## 🛠️ Стек технологий

- **Язык**: Kotlin 2.0.21
- **UI**: Jetpack Compose, Material 3, Single Activity Architecture
- **База данных**: Room + SQLCipher + Android Keystore
- **Архитектура**: Clean Architecture + MVI/MVVM (Domain UseCases, StateFlow, Repository Pattern)
- **Импорт / Экспорт**: Парсер выписок 1С (текстовый формат `1CClientBankExchange`), экспорт ОПиУ (P&L) в CSV
- **Тестирование**: JUnit 4, Robolectric, StateFlow Test Verification

## 🚀 Сборка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/KBAPTETus/kub.git
cd kub

# Запуск тестов
./gradlew testDebugUnitTest

# Сборка debug APK
./gradlew assembleDebug
```
Скомпилированный APK будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.
